# ATM Management System

A Python-based ATM system featuring user authentication, balance inquiry, deposit, and withdrawal functionalities.

## Features
- **User Authentication:** Create an account with a secure PIN and log in securely.
- **Transactions:** Deposit and withdraw funds with immediate balance updates.
- **Account Dashboard:** Check your balance and review a comprehensive transaction history.
- **Persistent Storage:** Utilizes JSON file handling (`users.json`) to persist user credentials and transaction data across sessions.

## Tech Stack
- **Language:** Python 3
- **Data Storage:** JSON (File I/O)

## How to Run
1. Ensure you have Python installed on your system.
2. Run the application from your terminal:
   ```bash
   python atm.py
   ```
3. Follow the on-screen prompts to create an account or log in.
